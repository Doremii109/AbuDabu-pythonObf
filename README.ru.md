# AbuDabu-pythonObf
Хороший AST обфускатор для Python с открытым исходным кодом

## Запуск
### Для Windows
`git clone https://github.com/Doremii109/AbuDabu-pythonObf`<br>
`cd AbuDabu-pythonObf`<br>
`python AbuDabu_Obf.py`

### Для Termux
`pkg install git`<br>
`pkg install python3`<br>
`git clone https://github.com/Doremii109/AbuDabu-pythonObf`<br>
`cd AbuDabu-pythonObf`<br>
`python AbuDabu_Obf.py`
